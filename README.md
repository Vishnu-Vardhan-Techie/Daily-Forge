# Daily-Forge
 
daily-forge is my daily practice log for full-stack development. Each day I work through one focused exercise and write up how it works, so the reasoning is as visible as the code.
 
## Approach
 
I want to understand why things work, not only how to make them run. For every exercise, I explain:
 
- **What** it does
- **Why** it is built this way
- **What happens under the hood** when it runs
- **Trade-offs** I considered and rejected
- **Mistakes** I made and how I fixed them
